## 📌 บทนำและแนวคิดโครงการ (Executive Summary)

**RESTPOINT** (ชื่อแนวคิด) หรือ **ToiletGo** (ชื่อผลิตภัณฑ์สำหรับสื่อสารกับผู้ใช้งาน) เป็นแพลตฟอร์มดิจิทัลที่พัฒนาขึ้นเพื่อแก้ปัญหาพื้นฐานแต่สำคัญยิ่งในการเดินทาง:
> *"เดินทางมั่นใจขึ้น เพราะรู้ล่วงหน้าว่าจะพักที่ไหน และสถานที่นั้นเหมาะกับเราหรือไม่"*

โครงการไม่ได้บอกเพียงแค่ว่า **"มีห้องน้ำ"** แต่ช่วยตอบคำถามว่า **"ห้องน้ำนี้เหมาะกับฉันหรือไม่"**
- มีสายฉีดชำระหรือไม่?
- พื้นแห้งสะอาด กลิ่นเป็นอย่างไร มีแม่บ้านดูแลหรือไม่?
- มีโต๊ะเปลี่ยนผ้าอ้อม หรือห้องให้นมบุตรสำหรับครอบครัวที่มีเด็กเล็กหรือไม่?
- ผู้พิการและผู้ใช้รถเข็น (Wheelchair) สามารถเข้าใช้งานได้จริงหรือไม่ (วัดความกว้างประตู ทางลาด ราวจับ รัศมีหมุนตัว 360 องศา)?
- ผู้สูงอายุเดินใกล้หรือไม่ พื้นไม่ลื่น แสงสว่างเพียงพอหรือไม่?
- มีห้องละหมาด ห้องอาบน้ำ หรือจุดพักรถระยะไกลหรือไม่?

## 🌟 ฟังก์ชันหลักบนเว็บแอปพลิเคชัน (Key Features)

1. **🗺️ Smart Restroom Map (แผนที่ห้องน้ำอัจฉริยะ):**
   - แสดงจุดห้องน้ำและจุดพักบนแผนที่ พร้อมระบุตำแหน่งปัจจุบันผ่านระบบ GPS
   - ค้นหาตามชื่อสถานที่ ปั๊มน้ำมัน ห้างสรรพสินค้า ศูนย์ขนส่ง สวนสาธารณะ หรือเส้นทาง
   - คำนวณระยะทางและเวลาเดินทาง พร้อมปุ่มเปิดระบบนำทางจริงผ่าน Google Maps

2. **🔍 Advanced Facility & Inclusivity Filters:**
   - กรองตามความต้องการเฉพาะ: สายฉีดชำระ, ห้องน้ำแยกชาย/หญิง, ห้องน้ำครอบครัว, โต๊ะเปลี่ยนผ้าอ้อม, ห้องให้นมบุตร, ห้องละหมาด, ห้องอาบน้ำ, จุดเติมน้ำ, จุดกางเต็นท์, ฟรี/มีค่าบริการ, เปิด 24 ชม.

3. **♿ มาตรฐานการเข้าถึงและการตรวจสอบจริง (Universal Design Audit):**
   - แยกป้ายสัญลักษณ์ออกจากการใช้งานได้จริง ตรวจวัดความกว้างประตู ทางลาด และพื้นที่หมุนตัว
   - แสดง 4 สถานะความน่าเชื่อถือ: `ยืนยันแล้ว`, `ผู้ใช้รายงาน`, `ยังไม่ทราบ`, `ไม่สามารถใช้งานได้ในขณะนี้`

4. **⭐ ระบบประเมิน 6 มิติ (Multi-dimensional Trust Rating Engine):**
   - ความสะอาด, อุปกรณ์, การเข้าถึง, ความปลอดภัย/เป็นส่วนตัว, ความสะดวก, และความคุ้มค่า
   - ป้ายจัดอันดับมาตรฐาน: *Top Rated, Cleanest, Family Friendly, Wheelchair Accessible, Senior Friendly, Best Facilities, Recently Verified*

5. **🚗 Route Rest Planner & Smart Reminder (ระบบวางแผนจุดพักบนเส้นทาง):**
   - วางแผนจุดแวะพักตามเส้นทางหลวงยอดนิยม (เช่น มอเตอร์เวย์ กรุงเทพฯ-พัทยา, พระราม 2 กรุงเทพฯ-หัวหิน, มิตรภาพ กรุงเทพฯ-เขาใหญ่)
   - กำหนดระยะเวลาพักรถ (ทุก 60, 90, 120 นาที) พร้อมระบบจำลองการแจ้งเตือนเพื่อความปลอดภัยของผู้ขับขี่

6. **➕ ชุมชนร่วมสร้างข้อมูล (Crowdsourcing & Verification):**
   - ประชาชนสามารถร่วมปักหมุดจุดห้องน้ำใหม่ เขียนรีวิว ให้คะแนน และแจ้งปัญหาอุปกรณ์ชำรุด

## 🛠️ สถาปัตยกรรมเทคโนโลยี (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **Styling & Design System:** Tailwind CSS + Responsive Mobile/Desktop UI
- **Maps & Geospatial:** Leaflet.js + OpenStreetMap Tiles
- **Icons & Visuals:** Lucide React + Canvas Confetti
- **Deployment Platform:** Vercel (Single-Page Application with custom rewrite rules)

## ☁️ การ Deploy ขึ้น Vercel (Deploy on Vercel)

1. เข้าไปที่ [Vercel Dashboard](https://vercel.com)
2. คลิก **"Add New..."** -> **"Project"**
3. เลือก Import จาก GitHub Repository: `ding1095/restpoint-toiletgo`
4. การตั้งค่า Framework Preset จะถูกเลือกเป็น **Vite** โดยอัตโนมัติ
5. คลิก **"Deploy"** รอประมาณ 30 วินาที เว็บไซต์จะออนไลน์ทันทีทั่วโลก พร้อม SSL HTTPS และ Global Edge CDN ฟรี!
