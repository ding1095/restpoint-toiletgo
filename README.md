# Poo Poo (ปู้ปู้) 💩✨

> **ปวดเมื่อไหร่บอกปู้ปู้! ค้นหาห้องน้ำสะอาดและจุดแวะพักระหว่างเดินทาง**  
> *Your Journey. Your Comfort. Your Rest Stop.*

## 🌟 ฟังก์ชันเด่นของ Poo Poo (Key Features)

1. **🚗 ค้นหาห้องน้ำตามเส้นทาง (Start to Destination Route Scanner):**
   - **กำหนดจุดเริ่มต้น:** พิมพ์ชื่อสถานที่ (เช่น กรุงเทพฯ, รังสิต, สุวรรณภูมิ) หรือ **คลิกปักหมุดบนแผนที่** หรือ **ใช้ตำแหน่ง GPS ปัจจุบัน**
   - **กำหนดจุดหมายปลายทาง:** พิมพ์ชื่อสถานที่ (เช่น พัทยา, หัวหิน, เขาใหญ่, เชียงใหม่) หรือ **คลิกปักหมุดบนแผนที่**
   - คำนวณเส้นทางขับขี่จริง (OSRM Routing Engine) และ **สแกนค้นหาห้องน้ำทุกจุดบนเส้นทางให้อัตโนมัติ**
   - แสดงระยะทางจากจุดเริ่มต้น เวลาเดินทางโดยประมาณ คะแนนรีวิว และสิ่งอำนวยความสะดวก

2. **💩 น้องปู้ปู้ คาแรกเตอร์สุดน่ารัก (Poo Poo Mascot):**
   - คาแรกเตอร์ "น้องปู้ปู้" ช่วยแนะนำจุดแวะพัก ปลอบประโลมเวลาปวดท้องฉุกเฉิน และร่วมเดินทางไปด้วยกันทุกทริป

3. **🗺️ แผนที่สำรวจจุดใกล้ฉัน (Nearby Explorer):**
   - ค้นหาจุดพักรอบตัวในรัศมีใกล้เคียง พร้อมตัวกรองสำคัญ:
     - 💦 มีสายฉีดชำระ
     - ♿ ทางลาด & รองรับรถเข็น/วีลแชร์
     - 🧓 ราวจับช่วยพยุงสำหรับผู้สูงอายุ
     - 👶 โต๊ะเปลี่ยนผ้าอ้อม & ห้องดูแลทารก
     - ⏰ เปิด 24 ชั่วโมง
     - 💵 เข้าใช้ฟรี

4. **⭐ คะแนนรีวิวและมาตรฐานความสะอาด:**
   - คะแนนความสะอาดจริงจากผู้ใช้
   - รูปภาพประกอบและจุดสังเกตในสถานที่
   - ปุ่ม **"นำทางทันที (Google Maps)"** เปิดแอปนำทางได้ใน 1 คลิก

5. **➕ ปักหมุดจุดใหม่ (Crowdsourcing):**
   - ร่วมแบ่งปันจุดพักและห้องน้ำสะอาดให้กับเพื่อนร่วมทาง

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Responsive Mobile-first Design
- **Map & Routing:** Leaflet.js + OpenStreetMap Tiles + OSRM Real Routing
- **Deploy:** Vercel Ready with Single-Page Application rewrites

---

## 🚀 วิธีการทดสอบในเครื่อง (Local Run)


## ☁️ นำขึ้น Vercel (Deploy on Vercel)

1. เข้าไปที่ [Vercel Dashboard](https://vercel.com)
2. คลิก **Add New...** -> **Project**
3. เลือก **`ding1095/restpoint-toiletgo`**
4. คลิก **Deploy** เว็บไซต์จะออนไลน์พร้อมใช้งานทันที!
